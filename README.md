# Neil Weather 🌤️

A beautiful, responsive weather website for Santa Cruz, Occidental Mindoro with dynamic theming that changes based on weather conditions.

## Features

✨ **Dynamic Themes**
- ☀️ Sunny Vibe (Orange & Gold)
- 🌧️ Rainy Vibe (Purple & Blue)  
- ☁️ Cloudy Vibe (Dark Gray)

🔄 **Auto-Updates**
- Updates every 24 hours automatically
- Real-time weather display
- Next update countdown

📱 **Fully Responsive**
- Desktop, tablet, and mobile optimized
- Smooth scrolling navigation
- Modern website layout

## Location

**Santa Cruz, Occidental Mindoro, Philippines**
- Coordinates: 12.5°N, 121.1°E
- Climate: Tropical Maritime
- Avg Temp: 25-32°C

## Sections

- **Home** - Hero introduction
- **Weather** - Current conditions
- **Forecast** - 5-day predictions
- **About** - Climate information
- **Contact** - Footer with details

## Technologies

- HTML5
- CSS3 (Gradients, Animations)
- Vanilla JavaScript
